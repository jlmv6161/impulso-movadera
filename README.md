# Programa Impulso — Movadera

Herramientas de uso interno para proponer y evaluar productos del catálogo.

- `index.html` — portada con los accesos
- `hoja-de-costeo.html` — hoja llenable de costeo y precio (para el colaborador)
- `calculadora-regalias.html` — evaluación del Comité

Todo funciona sin internet: se puede abrir el archivo con doble clic. Los datos se guardan solo en
el navegador de cada persona, no se envían a ningún lado.

---

**Este repositorio es solo la capa pública de herramientas.** La documentación del programa
(reglamento, marco legal, pipeline, tablero de ideas) vive fuera de aquí y no se publica.

Para actualizar las herramientas: ejecutar `publicar.ps1`, que copia la versión más reciente desde
la carpeta de trabajo y la sube.
